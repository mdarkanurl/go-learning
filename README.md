# Go Learning

Practice code from my Go learning journey. Each folder is a standalone `main` package covering one chapter's topic.

## Chapters

| Folder | Topic |
| --- | --- |
| `chapter-one` | Basics: printing, slices, first program |
| `chapter-two` | Variables and data types |
| `chapter-three` | Functions |
| `chapter-four` | Structs |
| `chapter-five` | Interfaces and methods |
| `chapter-six` | Errors |
| `chapter-seven` | Loops and conditionals |
| `chapter-eight` | Variadic functions |
| `chapter-nine` | Maps |
| `chapter-ten` | Pointers |
| `chapter-eleven` | Goroutines |
| `practice` | Extra exercises (interfaces) |

## Running

```bash
go run chapter-one/main.go
go run chapter-eleven/main.go
go run practice/interface.go
```
